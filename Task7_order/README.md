### Задача 7. Навести порядок

Дан массив, состоящий из 𝑁 целых чисел.
Требуется вывести эти 𝑁 чисел в выходной файл, но в строго определённом порядке.
Каждое следующее выведенное число должно быть больше предыдущего или равно ему.

Формат входных данных
В первой строке записано целое число 𝑁 (1 ⩽ 𝑁 ⩽ 104) — количество элементов массива.
Во второй строке через пробел записано 𝑁 целых чисел, каждое из которых по модулю
не превосходит 105. 

Формат выходных данных
В единственной строке выводятся все 𝑁 элементов массива через пробел в указанном
порядке.

### Пример
input.txt | output.txt
----------|-----------
5         | 1 3 3 4 5
1 4 3 5 3 |
