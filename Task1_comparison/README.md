### Задача 1 Сравнение элементов
Дан массив из 𝑁 чисел: 𝑏1, 𝑏2, . . ., 𝑏𝑁 .
Требуется для каждого элемента массива 𝑏𝑖 посчитать количество
элементов 𝑏𝑗, стоящих правее (𝑖 < 𝑗), но меньших него (𝑏𝑖 > 𝑏𝑗 ).

### Формат входных данных
В первой строке записано целое число 𝑁 (1 ⩽ 𝑁 ⩽ 100).
Во второй строке через пробел записано 𝑁 целых положительных
чисел — значения элементов массива. Гарантируется, что значения
элементов не превосходят 100.

### Формат выходных данных
Выведено 𝑁 целых чисел через пробел: по порядку для каждого
элемента входного массива выведено количество элементов,
удовлетворяющих описанному выше условию.

### Пример
input.txt | output.txt
----------|-----------
5         |
4 3 5 1 2 | 3 2 2 0 0

### Пояснение к примеру
Правее числа 4 стоят числа 3, 5, 1 и 2, три из которых имеют значение меньше 4.
